# Available reference machines

Axiado signature build
Internal full-build machine
```text
gb200nvl-bmc-axiado
gb300nvl-bmc-axiado
```

Github signature build
Intended for GitHub/public builds (uses partial binary releases sourced from GitHub)
```text
gb200nvl-bmc-axiado-github
```

Details about Nvidia's design can be found in the [docs](https://github.com/NVIDIA/nvbmc-docs)
repository.
